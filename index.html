Alur Sistem

Bagaimana Meterr.id bekerja

Dari sensor fisik hingga tampil di layar Anda, hanya dalam hitungan milidetik.

1

Loadcell + HX711

Sensor loadcell mengukur berat, dibaca oleh modul amplifier HX711.

2

ESP32

Mikrokontroler ESP32 membaca nilai HX711 dan mengirimkannya via WiFi.

3

Firebase Realtime Database

Data disimpan di node /loadcell/live dan riwayat di /loadcell/history.

4

Dashboard Web

Website mendengarkan perubahan data secara realtime dan menampilkannya ke Anda.
